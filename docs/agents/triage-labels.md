# Triage 标签

下表把自动化流程使用的五种标准角色映射到 `lofivo/lofiBoard` 的实际标签。

| 标准角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不会处理 |

自动化流程提到某个角色时，使用表中对应的仓库标签字符串。

仓库标签改名时同步更新第二列。
