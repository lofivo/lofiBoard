# LaTeX 编辑框高度自动贴合源码

本决策取代 ADR 0002 中“手动编辑高度作为后续编辑最小高度”的部分，但保留编辑框与渲染框分离、编辑宽度持久化和左上角锚点等其余决策。

LaTeX 源码编辑框只把 `editWidth` 作为再次进入编辑态时的稳定尺寸。实际编辑高度必须根据当前编辑宽度、字号、字体样式和源码的 textarea `scrollHeight` 重新计算；输入、宽度调整和字号缩放后也按同一规则实时贴合。旧 `editHeight` 不得作为最小高度，提交时仅用实际贴合高度更新该字段，以兼容现有画板格式。

原因是属性栏修改字号后，历史 `editHeight` 会与当前排版脱节。继续把它当作下限会让编辑边框在内容已变矮时保留垂直空白，而编辑高度本质上可由编辑宽度和文本排版完整重建。
