# 文本元素分离编辑框与渲染框

仅 `text` 元素增加可选的 `editWidth`/`editHeight` 字段，编辑框位置不独立持久化，始终以元素左上角为锚点；旧文件缺少字段时回退到现有 `width`/`height`。编辑框用于源码输入，调整时保持编辑态；文字输入与编辑框调整属于同一编辑事务，提交或取消时一起处理。用户手动设置的编辑框尺寸持久保存，输入导致的临时自动撑高不覆盖该设置。现有 `height` 字段保留为渲染高度缓存，但非编辑态的渲染框高度必须由 DOM/LaTeX overlay 的实际内容重新计算，以元素左上角为固定起点且不保留人为留白；文字、宽度、字体、样式、文件加载或 LaTeX 渲染完成等任何排版变化都必须触发重新测量。编辑框实际高度不得小于完整容纳源码所需的高度。Canvas/启发式测量只作为 DOM 尚未可用时的兜底，不作为浏览器运行时的最终真值。
